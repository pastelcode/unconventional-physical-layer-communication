A 36-bit frame is split bit-by-bit across an infrared link and a one-bit-per-packet ESP-NOW lane, paced by a wired clock. This field guide animates every layer: the GPIO wiring, the frame bits, the lane interleave, the acknowledge exchange and the retry that saves a corrupted byte.

01 · Physical medium

Two boards, three channels

Every board has the same pinout. Each direction gets its own clock wire and its own infrared path; the radio carries the second bit of every pair. The clock is not a free-running oscillator — it is generated per cycle by whichever board is transmitting.

clock The wired metronome

GPIO23 is a push-pull output, LOW when idle. A transmitter raises it for 2 ms once per bit pair. The peer's GPIO22 sees a rising edge and samples the optical bit at that instant. Exactly 18 edges define one frame.

infrared One logical level, one wire

GPIO18 drives an emitter through a transistor; GPIO26 reads a conditioned detector. The logical level must be stable when the clock edge arrives. A 38 kHz demodulating receiver needs timed bursts, not a static level — measure the real front end.

ESP-NOW A packet that carries one bit

Each cycle sends exactly one ESP-NOW application message. Its 7-byte envelope carries session, frame sequence, cycle index and the single lane bit. The whole 36-bit frame is never packed into one packet.

Wiring rules that prevent damage. Connect clock TX only to the peer's clock RX (never TX to TX), share ground, and do not tie the two 3.3 V rails together. Drive IR LEDs through a transistor with current limiting, keep clock wires short, and add 220–1000 Ω series resistors as a first lab precaution.

02 · Frame anatomy

A 36-bit sentence, field by field

SYN and SFD open the frame, a 4-bit CONTROL names the type, DATA carries a byte (or a NACK reason), and CRC-8 protects CONTROL + DATA. Build one below; every other panel on this page follows your choice.

'A'

Hex 0x00–0xFF. A text byte becomes one DATA frame.

DATA is reserved 0x00 for ACK, TURN and END. Correlation uses the sequence number, not a payload value.

Both boards must be built with the same profile. v1.0 wire default is SMBUS.

Swipe the bit strip sideways to see all five fields.

SYN training

Hover or click a field or a bit to inspect it.

Most significant bit first

Within every field the leftmost bit is sent first. The 36 serialized bits are paired in order — no field is reordered between lanes.

CONTROL is 4 bits

Only 0x1–0x5 are valid. ACK, TURN and END reserve DATA = 0x00; NACK uses DATA as its reason code.

CRC covers two bytes

CRC-8 is computed over [CONTROL & 0x0F, DATA] only. SYN, SFD and the CRC byte itself are excluded.

03 · Lane interleave

IR takes the even bits, ESP-NOW the odd

Pair sequential bits, not blocks. Cycle k carries logical bit 2k on infrared and 2k+1 on ESP-NOW. The receiver rebuilds every pair in IR-then-ESP-NOW order.

What if you concatenated lanes instead?

18 IR bits followed by 18 ESP-NOW bits is not the frame. The resulting stream cannot produce the SYN/SFD pattern:

BAD_FRAMING

A missing lane packet leaves its cycle slot empty. It never shifts later bits left; the transaction either times out or answers NACK 0x03.

04 · Cycle pacing

The clock waits for the radio

There is no periodic 500 Hz clock. The transmitter asserts the IR symbol, submits one ESP-NOW packet, waits for its local send callback and a guard interval, then pulses CLK_TX. The receiver joins late packets by cycle index, so the edge may precede or follow the packet.

    A full ACK is a frame

    ACK and NACK travel on both data lanes with the receiver's own clock — all 36 bits, not a single ESP-NOW control packet.

    Same sequence on retry

    A retransmission keeps frame_seq. The responder recognises the duplicate and re-sends its cached ACK.

    No ACK of ACK

    Responses are never acknowledged. A lost ACK is recovered by the sender's timeout and retry, not by an infinite reply loop.

    06 · Reliability

    One bit per packet, one delivery per sequence

    ESP-NOW is packet-based, so the protocol emulates a lane at the logical level: one packet per cycle carrying a single lane bit plus correlation metadata. ACKs confirm complete frames; a CRC detects corruption but cannot prove perfection.

    Transport envelope · 7 bytes per lane bit

    Not part of the 36-bit logical frame. It only prevents delayed or duplicated packets from landing in the wrong cycle.

    7 bytes total per application message: version, big-endian session ID, big-endian frame sequence, cycle index (0–17) and the lane bit (must be 0 or 1). Wi-Fi MAC overhead is additional.

    18 one-bit ESP-NOW messages per full frame. Never one packed frame.

    Duplicate delivery protection

    The ACK may be lost after the receiver accepted the DATA. The retry must not print the byte twice.

    CRC-8 lab

    Type ASCII text to see the profile's check behaviour. For a frame, the input is CONTROL (low nibble) followed by DATA.

    0xF4 CRC-8/SMBUS("123456789") — matches the catalogue check value

    What reliability cannot do

    • CRC-8 detects many corruption patterns but cannot guarantee detection of every one. An ACK confirms frame checks, not mathematical perfection.
    • Infrared ambiguity is usually caught by CRC; a LOW reading is not proof of an erasure — it may be a valid zero.
    • The static v1.0 session ID is a lab convenience. After independent reboots, old packets can collide with reused sequence numbers.
    • There is no parity, no per-bit ACK and no forward error correction. A missing ESP-NOW bit is a missing slot, not something to reconstruct.

    07 · State machine

    One serialized protocol task

    GPIO interrupts and Wi-Fi callbacks only enqueue events. A single task mutates transaction state, so transmission and response can never overlap. Click a state to inspect it.

    LINK_IDLE

    Waiting with no transaction in flight. The board may originate a new request if it owns the link, or accept an inbound clock burst from the peer.

    Event sources

    The clock ISR and the ESP-NOW receive callback copy a timestamp and bit into a queue, then return. No logging, allocation or state mutation happens there.

    Boundaries

    A partial attempt that emitted fewer than 18 edges is cleared by the quiet-gap rule: wait at least RX_FRAME_TIMEOUT + RESPONSE_START_GUARD before reusing the sequence.

    Role ownership

    A TURN frame is acknowledged like DATA. The receiver applies ownership before ACKing; the sender applies it only after validating that ACK.
